# 作业作答的识别与点击流程

本文描述当前程序如何找到浏览器、定位题目、点选选项。实现集中在 `auto_answer/homework.py`，入口是 `auto_answer/__main__.py`。

运行方式：

```text
python -m auto_answer
python -m auto_answer gui
python -m auto_answer parse
python -m auto_answer solve --model gpt-4o-mini
python -m auto_answer apply --window "作业作答 - Google Chrome"
python -m auto_answer verify
```

不带参数时打开桌面窗口。`apply` 只选择、勾选和填写，不会查找或点击「提交」「交卷」「暂时保存」。

## 总流程

```text
Chrome 或 Edge 中已打开的作业窗口
        |
        v
列出标题包含「作业作答」的窗口          browser.list_homework_windows
        |
        v
在文档「作业作答」里收集「题目 N. 」分组  collect_question_groups
        |
        v
读 runtime/answers.json 里该题的答案
        |
        +-- 单选：按字母 SelectionItemPattern.Select
        +-- 判断：按选项文字「对 / 错」再 Select
        +-- 多选：LegacyIAccessiblePattern.DoDefaultAction
        +-- 填空：点进题目内的编辑区，粘贴文本
```

题目文字的解析和页面上的点击是两条分开的路径。`parse` / `solve` 读的是事先复制下来的 `_page_text.txt`。`apply` 不再读题干，只按题号在页面上找控件。

## 1. 如何识别浏览器

代码路径：`auto_answer/browser.py` 的 `list_homework_windows`、`browser_name`、`connect_window`。界面在 `auto_answer/gui.py` 的「作业窗口」下拉框里调用它。

识别条件：

| 条件 | 当前取值 | 含义 |
| --- | --- | --- |
| 控件类型 | 桌面的直接子窗口 | 只看顶层窗口 |
| 标题 | 包含「作业作答」 | 超星作业页的文档标题 |
| 浏览器 | 标题含 `Google Chrome` 或 `Microsoft Edge` | 同时支持这两个浏览器 |

Chrome 的窗口标题一般是「作业作答 - Google Chrome」。Edge 一般是「作业作答 - Microsoft Edge」，带配置文件时会变成「作业作答 - 个人 - Microsoft Edge」。两种都算。标题里的零宽字符会被去掉后再判断。

窗口标题来自当前激活的标签。标签切走以后，标题不再包含「作业作答」，这个窗口就不会出现在列表里。

在界面里选中一项，或点「检测窗口」，会读取该窗口的作业名称、题量、`workId` 和地址，并让它在任务栏闪烁。多个标题相同的窗口因此可以区分开。写入和核对使用这次选中的窗口句柄。

只有一个匹配窗口时，命令行 `apply` 会直接使用它。有多个时必须在界面里选定，或给命令行加上 `--window` 完整标题。选中后 `apply_answers` 调用 `SetActive` 把该窗口放到前台。

## 2. 如何识别题目

页面上的题目和文本文件里的题目不是同一次查找。

### 2.1 页面上的题目分组

代码路径：`collect_question_groups`。

```245:256:auto_answer/homework.py

        raise SystemExit("没有在浏览器窗口里找到作业文档")
    found: dict[int, object] = {}

        if depth > 6:

```

步骤：

1. 在窗口内部、深度不超过 25 的位置，找名称为「作业作答」的 `Document`。这是网页文档，不是浏览器窗口标题。
2. 从该文档向下最多 6 层，查找名称完全匹配 `题目 N. ` 的分组。注意名称末尾有一个空格，正则是 `题目 (\d+)\. `。
3. 用题号 `N` 做字典键。后面按 `answers.json` 里的 `no` 取出对应分组。

这一层只用题号，不比较题干文字。分组的直接子节点里才有选项。

在这次超星页面上，无障碍名称形如：

| 题型 | 控件 | 名称示例 |
| --- | --- | --- |
| 单选 | `RadioButton` | `B 对象选择` |
| 多选 | `CheckBox` | `A 如果类中没有显式声明构造方法,则会自动提供默认构造函数。选择` |
| 判断 | `RadioButton` | `A对选择`、`B错选择` |

选项字母只取名称的第一个字符。名称必须以 `A` 到 `H` 开头。

### 2.3 填空编辑区

代码路径：`find_blank_editor`。

在题目分组内部向下查找 `Document`。超星把每一个空渲染成题目内部的一个文档编辑区。函数取找到的最后一个文档作为输入框。

### 2.4 题干文本从哪里来

代码路径：`load_page_text`、`parse_questions`，输入文件是项目根目录的 `_page_text.txt`。

这次作业的题干是从页面全选复制得到的，再按下面的形式切分：

```text
1. (单选题)
题干

A
选项内容

B
选项内容
```

支持的类型只有 `单选题`、`多选题`、`判断题`、`填空题`。题号必须从 1 连续排到最后一题，否则 `parse_questions` 直接报错。页尾的题号导航从「一. 单选题（65分）」开始被截掉，避免把导航数字再解析成题目。

界面打开时列表里可能是上次保存的题目。点「更新题目」会从当前选中的作业窗口重新复制并解析，然后才允许生成答案。`solve` 把解析结果按每 10 题发给 OpenAI 兼容接口，答案写入 `runtime/answers.json`。接口地址、模型名和 API Key 来自界面保存的 `runtime/openai.json`，也可以用环境变量 `OPENAI_BASE_URL`、`OPENAI_MODEL`、`OPENAI_API_KEY`，或命令行 `--base-url`、`--model`、`--api-key`。模型名可填 `gpt-4o`、`gpt-4.1`、`gpt-4o-mini`、`o4-mini` 等 OpenAI 系列名称。`apply` 只消费答案文件。配置读取在 `auto_answer/config.py`。

## 3. 如何点击选项

代码路径：`apply_answers` 循环调用 `choose_option` 或 `fill_blank`。点之前会用 `scroll_into_view` 把题目滚进可视区域。滚动使用控件的 `ScrollItemPattern`，没有「下一题」按钮可点。本次页面是一页列出全部题目。

### 3.1 单选

单选按答案字母找到名称以该字母开头的单选按钮，调用 `SelectionItemPattern.Select()`。这是无障碍接口里的选择动作，不是用坐标去点圆圈。同一组里的其他单选会被浏览器取消。

选完后立刻再读 `IsSelected` 可能还是旧状态，所以日志里出现过 `partial-`。以 `verify` 的结果为准。

### 3.2 判断

代码路径：`option_truth`、`desired_truth`，以及 `choose_option` 的 `judge` 分支。

判断题不假定 A 是对、B 是错。页面上可能是「A 对 / B 错」，也可能是「A 错 / B 对」。

1. 模型被要求返回「对」或「错」，不返回字母。
2. 如果答案仍是字母，就用当时解析到的选项文字把它换成「对」或「错」。
3. 写入页面时，读取每个单选按钮的名称。名称里出现「错」「错误」「不正确」视为错，出现「对」「正确」视为对。
4. 选中与答案含义相同的那一项，不管它现在排在 A 还是 B。

### 3.3 多选

```391:402:auto_answer/homework.py
        for control in controls:
            letter = option_letter(control.Name)
            should = letter in wanted
            if control_is_checked(control) == should:
                continue
            legacy = control.GetPattern(auto.PatternId.LegacyIAccessiblePattern)
            if legacy is None or not legacy.DoDefaultAction(waitTime=0.15):
                missed.append(letter)
                continue
            time.sleep(0.12)
            if control_is_checked(control) != should:
                missed.append(letter)
```

多选不使用 `SetChecked` 或 `Toggle`。在这个页面上，这两种调用会返回成功，勾选状态却不变。实际生效的是旧版无障碍接口的默认动作 `DoDefaultAction`：

- 未选中时，默认动作名称包含「选定」，执行后变为选中。
- 已选中时，默认动作名称包含「取消选定」，执行后变为未选中。

`control_is_checked` 先看默认动作名称，再退回 `ToggleState`。已经符合答案的选项不会再次执行默认动作，避免把正确选项取消。

填空依赖作业窗口处于前台，并且编辑区中心落在窗口可见范围内。

### 3.5 不点击提交

`FORBIDDEN_NAMES` 列出了「提交」「交卷」「暂时保存」「保存并提交」「确认提交」。`apply` 的循环只处理题目分组里的单选、多选和编辑区，不会按这些名称去查找按钮。`assert_not_forbidden` 已写好，但当前点击路径没有调用它。

## 5. 当前答题操作是否通用

对超星「作业作答」这一套页面是可以复用的。Chrome 和 Edge、不同课程，只要还是这个页面结构，就可以用同一套识别和点击。判断题会按「对 / 错」文字匹配，不依赖 A、B 的固定顺序。

可以复用的部分：

- 题号连续的单选、多选、判断、单空填空。
- 窗口标题包含「作业作答」，浏览器是 Chrome 或 Edge。
- 文档名是「作业作答」，题目分组名是「题目 N. 」。
- 选项是分组的直接子节点，单选和多选的名称以 `A`–`H` 开头。
- 判断选项的名称里含有「对」或「错」。
- 题目已经全部渲染在同一页。

仍然覆盖不到的情况：

| 情况 | 原因 |
| --- | --- |
| Firefox，或标题里没有「作业作答」 | 只识别 Chrome 与 Edge 的作业窗口 |
| 作业列表、课程页、考试页 | 文档标题不是「作业作答」 |
| 一题一页，需要点「下一题」 | 代码只滚动当前页上的「题目 N. 」 |
| 分组名不是「题目 N. 」 | 页面定位只认这个名称 |
| 简答题、多空填空、附件题 | 没有对应控件处理 |
| 题目分页，未出现的题不在树上 | 收集不到分组就会中止 |
| 其他学习平台 | 文档名、分组名、选项名称都不同 |

`parse` 仍依赖复制文本的换行格式。页面改版后，点击结构还在时，题干解析也可能失败。

## 6. 多个「作业作答」标签如何处理

一次写入只处理界面里选定的那一个窗口，也就是该窗口当前激活的标签。

同一个浏览器窗口里如果有两个作业标签：

- 只有正在显示的标签会让窗口标题包含「作业作答」。
- 后台标签不在当前文档树里，`collect_question_groups` 看不到它的题目。
- 程序不会自动切换标签。

多个窗口同时打开时，界面的「刷新窗口」会把它们都列出来，包括 Chrome 和 Edge。写入和核对使用下拉框里选定的那一个。命令行有多个匹配窗口时，需要用 `--window` 传入完整标题，否则会停下来并列出标题。

实际操作：把要作答的作业标签切到前台，刷新窗口，选中这一项，再点「写入页面」。其他作业标签保持不动。
